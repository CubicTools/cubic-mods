# Cubic Mods

Cubic Mods is a Windows app that adds extra features to the Steam version of Cubic Castles. Start the game, then open Cubic Mods and it attaches to it.

## Download

Get `cubic-mods-<version>.exe` from the [Releases](../../releases) page.

## Install

1. Download the exe and put it anywhere (your Desktop is fine).
2. Start Cubic Castles from Steam.
3. Double-click `cubic-mods.exe`. If Windows SmartScreen pops up, click **More info** → **Run anyway**.

## Hotkeys

| Key | What it does |
|-----|--------------|
| F1  | Voice typing into the chat box |
| F3  | Realm lighting: original / bright / full bright |
| F5  | Camera: normal / first-person / third-person |
| F7  | Market search, then warp to the machine selling it |
| F8  | Price of the item on screen |
| F9  | Block finder |
| F10 / F11 | Multi-break / multi-build |
| F12 | Performance HUD |

Everything can also be switched on and off from the Cubic Mods window.

## Updates

Click **Check for updates** in the app. It downloads the new version and restarts itself.

## Tips

- If a feature stops working after a Cubic Castles update, check for a Cubic Mods update.
- The price lookup (F8) needs Tesseract OCR installed: `winget install UB-Mannheim.TesseractOCR`.
